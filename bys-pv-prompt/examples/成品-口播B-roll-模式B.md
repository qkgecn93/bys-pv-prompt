# 成品范例 · 口播 B-roll · 模式 B（时间码对齐）

**存在意义**：演示低密度档、时间码切段、风格锁逐字复制。这是本 Skill 实测跑出来的真实产出，不是手写的理想样本。

**题目**：40 秒口播《为什么你收藏了那么多干货却一个都没看》配画面
**参数**：即梦 / 单段上限 15s / 9:16 / 冷蓝都市 / 无面剪影 / **密度 0.5–0.8 切每秒**（有人声压在上面，锁低密度）
**产出**：6 段共 28 个画面

> 注意这里对"游戏 PV 感"的处理：用户原话要的是 PV 感，Skill 把它判定为**美术风格词而非密度授权**，所以给了 PV 的美术（赛璐璐 + UI 线稿 + 反相 + 匹配转场），密度仍锁在 B-roll 档。这是 §三 Step 2 那条判据的实际应用。

## 提示词节选

下面只放第 1 段和第 3 段。**六段的声明句、【画面】、【动效要求】三块逐字相同**——这正是风格锁的要求，此处不重复贴出，实际交付时每段都要完整带上。

第 3 段是全片两处**图形匹配转场**之一（卡片矩阵塌缩 → 时钟圆环），落在语义转折处（"东西多" → "没时间"）。

### 第 1 段 · 00:00.0 – 00:06.0

```
生成一支6秒、9:16竖版、纯二维日式赛璐璐动画结合抽象Editorial MG平面设计的口播垫片B-roll片段。全片保持纯二维平面，禁止3D，禁止立体建模，禁止真实空间纵深，禁止三维透视渲染，禁止CG质感。原创画面，不出现任何真实企业Logo、真人形象、现成素材与任何真实App界面。

【音乐】
112BPM冷调极简电子，融合低频脉冲、干净电子鼓、稀疏钢琴单音、翻页声、点击声与数据滚动音效，整体音量压低，作为人声下方的垫底节奏。本段没有任何人声、旁白与歌词。本段处于全片开场，鼓点在第二秒切入并保持稳定推进，段尾不做收束。

【画面】
冷蓝视觉风格：深海蓝、钴蓝、青蓝、纯白与黑色构成高反差画面，猩红色只用于焦虑与警示。硬边日式赛璐璐结合扁平Editorial MG与游戏UI线稿。一切元素高度平面化、图形化、剪影化，像一张动态平面海报被不断拆解和重新组合，空间允许不合理倾斜、翻转与压缩。

人物为无面黑色剪影，只有肩线与头部轮廓，没有五官，没有材质，没有立体光影，阴影只有一至两层；剪影的肩线边缘、胸口与手部可作局部特写。

收藏与信息囤积不表现为真实手机界面或App截图，只由二维图形构成：矩形内容卡片（卡内只有灰色横线占位，不出现任何可读文字）、文件夹梯形标签、星形线稿、堆叠层块、俯视网格、时钟刻度圆环、进度环、同心圆、密度网点、数字计数器、扫描线、遮罩条、几何切片、斜向色块与游戏UI框线。构图大面积留白，元素在每个画面之间不断更换组合。

【镜头节奏】
0–6秒：本段共4个画面，平均每一点五秒切换一次。纯白背景中一枚深海蓝无面剪影侧身定格，剪影手中一枚青蓝色矩形卡片单帧亮起。单帧白闪后三枚钴蓝色文件夹梯形标签自画面下缘硬切弹入，横向对齐成一排。切入标签边缘的局部特写，白色细线刻度沿边缘逐格弹亮。画面硬切回满屏全景，标签后方瞬间阵列出同构标签网格，右侧白色数字计数器跳到三位数后定格。

【动效要求】
所有转场跟随鼓点完成。本段为无旁白的纯画面垫片素材，画面中没有任何人物开口说话，不需要口型，不出现说话的嘴部特写；剪辑点只跟随鼓点均匀推进，不对应任何台词，不做完整叙事的起承转合。

所有形态变化以弹出、闪现、劈入、划过、反相、碎裂、塌缩、拼合和图形替换完成，不使用生长、展开、浮现等渐进动作。使用斜向擦除、圆环扩张与塌缩、剪影反相、图形拆解、单帧白闪、蓝白负片闪烁、图形匹配转场与短促Glitch。景别在满屏全景、中景与局部特写之间跳切，连续两个画面不使用相同景别。运镜只允许平面内的平移、缩放与快速推近，不允许任何三维镜头运动。
```

## 这份范例演示了什么

| 规则 | 体现 |
|---|---|
| 密度句在【镜头节奏】首句 | 「本段共 4 个画面，平均每一点五秒切换一次」 |
| 密度按用途锁档 | 全片 0.5–0.8 切每秒，未被"要 PV 感"带偏 |
| 风格锁三样逐字复制 | 六段的声明句 /【画面】/【动效要求】字节相同 |
| 【音乐】不裸省 | 每段保留音乐块，只有段落位置描述按段变 |
| 画面内无中文 | 卡片内只有灰色横线占位，文字全部后期加 |
| 瞬间性动词 | 弹入、闪现、劈入、塌缩、碎裂，零渐进动词 |
| 题材追加禁令 | 点名禁掉真实手机/App 界面——这个题材最容易被画成写实截图 |
| 图形匹配转场 | 卡片矩阵→时钟圆环、网点→胸口光点，各落在语义转折处 |
