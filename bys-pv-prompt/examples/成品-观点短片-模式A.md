# 成品范例 · 非游戏题材 · 15 秒观点短片（模式 A）

**存在意义**：证明 L4 换血后风格依然成立。下面这段的配色规则、剪影处理、场景平面化写法、禁令清单全部逐字来自游戏 PV 参考，但一个游戏符号都没有。

**观点**：AI 正在让普通人第一次用极低的成本，获得过去只有公司才拥有的组织能力
**参数**：15s / 16:9 / 冷蓝 / 题材=组织协作 / 动效密度=高（独立成片）/ 无面剪影
**文案**：53 字（15 秒按八折算），中段留 3.4 秒纯音乐爆发窗口

---

```
生成一支15秒、16:9横版、纯二维日式赛璐璐动画结合抽象Editorial MG平面设计的高强度观点短片，节奏对标高密度游戏宣传PV。全片保持纯二维平面，禁止3D，禁止立体建模，禁止真实空间纵深，禁止三维透视渲染，禁止CG质感。原创画面，不出现任何真实企业Logo、真人形象或现成素材。

【音乐】
132BPM冷调电子摇滚，融合电子鼓、低沉Bass、碎拍、稀疏钢琴单音、机械咬合声、翻页声与数据滚动声。开场只有低频脉冲和细碎点击，3秒后鼓点全面进入，5.6至9秒节奏加速并加入快速电子切片，9秒转为上扬合成器，结尾收在一记清脆单音后突然抽空。

中文男声画外音旁白，冷静克制，语速偏快，咬字干脆。旁白为画外音，画面中没有任何人物开口说话，不需要口型，不出现说话的嘴部特写。0至3秒念「过去，做成一件事得先有一家公司。」3.2至5.6秒念「招人、分工、协调，普通人碰不起。」5.6至9秒完全无旁白，只有音乐与画面。9至12.8秒念「现在，AI把这套东西压进了一个人手里。」12.8秒之后无旁白。

【画面】
冷蓝视觉风格：深海蓝、钴蓝、青蓝、纯白与黑色构成高反差画面，猩红色只用于门槛与警示。硬边日式赛璐璐结合扁平Editorial MG与游戏UI线稿。一切元素高度平面化、图形化、剪影化，像一张动态平面海报被不断拆解和重新组合，空间允许不合理倾斜、翻转与压缩。

人物为无面黑色剪影，只有肩线与头部轮廓，没有五官，没有材质，没有立体光影，阴影只有一至两层；剪影的肩线边缘、胸口与手部可作局部特写。组织结构不表现为真实办公场景，只由二维图形构成：人形剪影节点、白色连线网、层级树线框、矩形方块阵列、圆环、齿轮线稿、细线刻度、数字计数器、网格、扫描线、网点、几何切片、斜向色块与游戏UI框线。构图大面积留白，元素在每个画面之间不断更换组合。

【镜头节奏】
0–3秒：纯白背景中一枚深蓝色人形剪影闪入画面，肩线边缘亮起青蓝色轮廓光。单帧白闪后，剪影头顶弹出白色细线与两个节点，层级树整层向两侧炸开。单个节点方块被网点覆盖并占满画面。金字塔状组织结构瞬间铺满全屏，深蓝节点密布，画面右侧的白色刻度条整条弹亮。

3–5.6秒：白色连线一次性铺满整张网。人形剪影阵列高速填入网格，矩形方块分裂成三组各自对齐，齿轮线稿与圆环叠加咬合旋转。画面蓝白反相一帧。俯视网格被黑色斜向色块横穿，切成多个不规则区域；刻度数字在特写中高速滚动。

5.6–9秒：鼓点爆发，进入快速抽象MG蒙太奇。组织树线框、连线密网、错位方块阵列、旋转圆环、滚动刻度、剪影局部轮廓、骤增网点与横扫的扫描线不断重叠、闪现、错位叠印，画面每三分之一秒更换一次。猩红色横向色块两次单帧劈入，极简英文文字「COST」一闪而过。每个鼓点触发一次蓝白反相或几何拆解。

9–12.8秒：厚重的猩红色横向色块横亘画面，孤立的深蓝剪影被压在下方仰头站立。切入胸口特写，一枚青蓝色光点亮起。猩红色块碎裂成几何切片向两侧飞散。上方整张组织密网的节点、连线、方块与刻度同时向内塌缩，收拢成一枚青蓝色光点；光点匹配转场为剪影胸口的那枚光点。单帧白闪后，完全相同规模的连线与节点以这枚剪影为唯一圆心一次性弹开。

12.8–15秒：剪影居中定格，青蓝色圆环出现并旋转，环上刻度逐格弹亮。画面反相一帧后恢复，定格收尾。

【动效要求】
所有转场跟随鼓点完成，全片保持极高剪辑密度，画面平均每零点四秒切换一次。画面剪辑点只跟随鼓点，不跟随旁白的句子边界，一句旁白横跨七到八个画面，允许在句子中间切换画面；严禁一句台词对应一个画面。

所有形态变化以弹出、闪现、劈入、划过、反相、碎裂、塌缩、拼合和图形替换完成，不使用生长、展开、浮现等渐进动作。使用斜向擦除、圆环扩张与塌缩、剪影反相、图形拆解、单帧白闪、蓝白负片闪烁、图形匹配转场与短促Glitch。景别在满屏全景、中景与局部特写之间高频跳切，连续两个画面不使用相同景别。运镜只允许平面内的平移、缩放与快速推近，不允许任何三维镜头运动。

避免节奏拖沓、长镜头、平滑生长动画、缓慢展开、画面跟着句子走、普通淡入淡出、渐变过渡、写实3D、立体建模、真实透视、景深、CG质感、真实办公室场景、真实电脑与手机设备、暖色阳光、霓虹赛博朋克街景、杂乱文字、人物开口说话的镜头。
```

## 这个范例演示了哪几条铁律

| 铁律 | 在哪体现 |
|---|---|
| 动词决定速度 | 全篇只有闪入、弹出、炸开、铺满、劈入、碎裂、塌缩、弹开；零个"生长/展开/浮现" |
| 短句流 | 每个时间段 5–7 短句，句号即剪辑点；无编号 |
| 密度给数字 | 【动效要求】里"平均每零点四秒切换一次"作为散文句 |
| 双轨解耦 | 台词轨在【音乐】块给时间点，【镜头节奏】按自己节奏走；解耦声明写死 |
| 并列一词一刀 | 「招人、分工、协调」对应三个画面（剪影填入 / 方块分裂 / 齿轮咬合） |
| 留爆发窗口 | 5.6–9 秒无旁白，纯音乐 + 最密集的 MG 蒙太奇 |
| 图形匹配转场 | 密网塌缩成的青蓝光点 → 匹配为剪影胸口的光点 |
| 景别层次 | 满屏全景 / 中景 / 胸口特写 / 刻度数字微观特写交替 |
| L4 换血 | 符号全部来自「组织协作」库，无任何游戏元素 |

## 这个范例的演进史

v1 只有 4 个画面（3.8 秒/镜），用户反馈"节奏慢、MG 切换感不够"。
问题依次是：动效密度参数选错（拿 B-roll 逻辑套独立短片）→ 用了渐进性动词 → 旁白铺满没有爆发窗口 → 台词轨与镜头轨没解耦 → 中途一度改成编号清单反而更糟。

六条铁律就是这个过程的产物。
