# 概念可视化映射

**这是把"口播说了什么"翻译成"画面做什么"的核心资产。**

两层交叉出画面：上层决定用什么**物件**，下层决定这些物件**怎么动**。

---

## 上层 · 题材 → L4 符号库

换掉 L4 就是换题材，L1–L3 风格锁一字不动。

| 题材 | 符号库 |
|---|---|
| **新闻 / 时事** | 人形剪影阵列、地图轮廓线、柱状与折线刻度、报纸版式栅格、日期数字、印章方块、引号符号、话筒剪影 |
| **科技 / AI** | 节点点阵、连线网络、芯片方格、终端光标、进度环、代码行剪影、数据流线、开关符号 |
| **商业 / 财经** | 曲线刻度、货币符号、方块堆叠、天平、齿轮线稿、合同版式、层级树、饼形分割 |
| **故事 / 叙事** | 无面人形剪影、门框、窗格、道路线、时钟、行李箱、路灯、椅子剪影、信封 |
| **知识 / 科普** | 几何体线稿、箭头、公式排版、层级树、放大镜圆环、分子点线、书页矩形、坐标轴 |
| **心理 / 情绪** | 同心圆、密度网点、破碎色块、镜面对称、单人剪影与巨大留白、绳结线条、镜框 |
| **组织 / 协作** | 人形节点、连线网、层级树线框、方块阵列、齿轮咬合、分工色块、圆桌轮廓 |
| **时间 / 变化** | 时钟圆环、刻度环、月相、沙漏几何化、日历栅格、年轮同心圆、倒计时数字 |

**没列到的题材怎么办**：问自己"这个领域的人会在白板上画什么"，那就是它的符号库。保持 6–10 项，且必须能被平面化成线稿或纯色块。

---

## 下层 · 叙事功能 → 图形动作

题材无关，永远复用。

| 概念 | 图形化 |
|---|---|
| 增长 / 爆发 | 圆形从中心扩散，刻度条飙升，网格向外炸裂 |
| 崩塌 / 失控 | 矩形色块矩阵向下坍塌，网点密度骤增 |
| 选择 / 分叉 | 画面斜切两半，两组对立色块拉开 |
| 信息过载 | 卡片以网格快速堆叠覆盖直至满屏，扫描线加密 |
| 时间流逝 / 倒计时 | 时钟圆环旋转，刻度逐格熄灭，月相碎裂 |
| 对抗 / 博弈 | 黑白剪影分居两侧，中央分割线抖动 |
| 揭示 / 真相 | 遮罩横向擦除，单帧反相闪白 |
| 循环 / 陷阱 | 图形首尾相接做莫比乌斯式循环运动 |
| 连接 / 网络 | 节点点阵，线条逐条点亮 |
| 筛选 / 淘汰 | 密集图标阵列中大部分变灰，少数保留原色 |
| 突破 / 转折 | 斜向刀刃形色块划过，画面反相后重组 |
| 积累 / 复利 | 同一图形逐层叠印，层数递增，色相逐级加深 |
| 压缩 / 收敛 | 满屏元素同时向内塌缩，收拢成一点 |
| 释放 / 赋能 | 一点向外一次性弹开成完整结构 |
| 门槛 / 壁垒 | 厚重横向色块横亘画面，主体被压在下方 |
| 分裂 / 拆解 | 整块图形沿斜线裂成几何切片飞散 |
| 对比 / 落差 | 画面纵向分割，两侧同构图形尺寸悬殊 |
| 隐藏 / 被忽视 | 主体被网点或扫描线覆盖至几乎不可见 |
| 秩序 / 规则 | 元素瞬间对齐到网格，多余部分被裁切 |
| 混乱 / 无序 | 元素错位叠印，旋转角度各不相同 |
| 稀缺 / 唯一 | 满屏同构元素，只有一个保留高饱和色 |
| 传播 / 扩散 | 圆环从一点连续扩张，触及的节点依次亮起 |
| 停滞 / 困住 | 图形做往复运动但始终回到原位，刻度不前进 |
| 觉醒 / 转变 | 剪影反相为负形后不再复原，轮廓光换色 |
| 规模化 / 复制 | 单个图形瞬间阵列化成网格，数量爆炸 |
| 消耗 / 代价 | 进度环逆向减少，刻度逐格熄灭，点缀色闪现 |

**用法**：一个语义单元先在下层找叙事功能，再到上层取该题材的符号去填充。

**例**：口播「某公司裁员两万人」
→ 下层【筛选 / 淘汰】：密集阵列中大部分变灰
→ 上层【新闻】：人形剪影阵列 + 数字刻度
→ 分镜：*纯白背景铺满深蓝人形剪影网格。八成剪影单帧反相为白色负形并向下碎裂。红色计数器数字飙至 20000 后定格闪一帧猩红。黑色斜切色块自右上横扫，将剩余剪影与刻度一并切走。*

## 场景平面化通法

任何真实场景都能进这个风格：**抽出 3–5 个标志性构件 → 白色线稿 + 矩形色块 + 网格 + 大面积留白**。

不要画完整场景。参考里处理城市的原话就是通法本身：

> 城市被高度平面化，只保留管道、空调外机、窗框、电线和高楼轮廓，以白色线稿、矩形色块和网格构成。

| 场景 | 保留的构件 |
|---|---|
| 城市街道 | 管道、空调外机、电线、窗框、高楼轮廓 |
| 便利店 | 货架线稿、冰柜矩形、自动门框、荧光灯管横线 |
| 办公室 | 工位网格、百叶窗横线、显示器矩形、隔断色块 |
| 教室 | 课桌阵列、黑板矩形、窗格、吊灯圆点 |
| 地铁 / 通勤 | 车门框、扶手竖线、座椅色块、隧道横线 |
| 家 / 卧室 | 床矩形、窗框、台灯圆环、门缝光条 |
| 会议室 | 长桌轮廓、椅背剪影阵列、投影矩形、白板线框 |
| 医院 | 走廊透视线（改为平行线）、床帘竖褶、点滴架细线、指示牌方块 |

选构件的标准：**能一眼认出是哪儿，且能被画成线或色块。** 不满足第二条的一律不要（比如"绿植""咖啡杯"就不适合，形状太软）。

## 不适用清单

需要**具体真实物件辨识度**的内容不适合本风格：

- 某款具体产品（手机、汽车、包）——平面化后就不是那个型号了
- 某道具体的菜 / 食物——质感是主体，剪影化后全无意义
- 某个真实地标 / 城市天际线——观众要认出它，抽象化后认不出
- 某个真人 / 名人——本风格禁止真人形象
- 需要展示 UI 界面细节的（软件教程、操作演示）——用录屏

遇到这类需求，直接说明并建议实拍、录屏或图生视频，不要硬套。硬套的结果是既不像那个东西，风格也不纯。
