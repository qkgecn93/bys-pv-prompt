## 1. 密度基准

逐镜数过的参考 PV 真实密度：

| 区间 | 画面数 | 密度 |
|---|---|---|
| 0–3s（开场铺垫） | 3 | 1.0 /s |
| 3–6s（推进） | 5 | 1.7 /s |
| 9–12s（高潮前） | 8 | 2.7 /s |
| 12–15s（MG 蒙太奇） | 6+ 且不断重叠 | 2.0+ /s |

**结论**：一支 20 秒 PV 约 30 个画面。开场可以疏，中后段必须密。

**对照实测的失败版本**：15 秒只有 4 个画面（3.8 秒/镜），用户反馈是「节奏慢了，MG 的切换感不够」。这就是 1.33 /s 以下的观感。

**分档建议**：

| 场景 | 目标密度 | 15 秒对应画面数 |
|---|---|---|
| 独立观点短片 / 片头 | 2.0–2.3 /s，爆发段 3 /s | 30–34 |
| 常规 B-roll | 0.5–0.8 /s | 8 秒段做 4–6 个 |
| 长时间垫底的 B-roll | 0.3–0.5 /s | 8 秒段做 2–3 个 |

**上限警告**：单次生成压到 2.3 /s 以上时，模型可能执行不了，糊成一片无意义闪烁。这时不要继续加码，改走**分段生成再拼**——每段 5 秒只写 8–10 个画面，模型压力小得多，拼起来的实际密度反而更高更可控。配合锚点帧策略做一致性。

## 2. 动词对照表（完整版）

**这是提速的第一杠杆。** 分镜里每一个动作动词都要从右栏选。

| 慢 · 渐进性（禁用） | 快 · 瞬间性（只用这些） |
|---|---|
| 生长、长出 | 弹开、弹出、炸开 |
| 展开、铺开（缓慢） | 一次性铺满、整层弹出 |
| 浮现、显现 | 闪现、闪入、亮起 |
| 逐渐形成、慢慢变成 | 拼合、重组、匹配为 |
| 缓缓移动、平移 | 划过、掠过、横扫 |
| 淡入、淡出、渐变 | 单帧白闪、反相、切 |
| 旋转（匀速持续） | 高速旋转、旋转一圈定格 |
| 变大、放大 | 放大成为、占满画面 |
| 消散、溶解（慢） | 碎裂、拆解、飞散 |
| 收缩、聚拢 | 塌缩、收拢成一点 |
| 打开、开启 | 劈入、切入、砸下 |

**副词也要管**：删掉"逐渐""缓缓""慢慢""平滑地""流畅地"。保留"瞬间""高速""快速""单帧"。

**低密度段想要"呼吸感"怎么办**：不要用持续性动作，更不要为此放开【动效要求】的禁令（那会破坏风格锁的逐字一致，是多段翻车的头号原因）。用瞬间动词达成同样效果——「圆环高速旋转一圈后定格」「刻度逐格弹亮后停住」，既有动感又不违反禁令。

## 3. 短句流写法拆解

拆解参考 PV 的一个时间段，看密度是怎么来的：

> 3–6秒：白色连线一次性铺满整张网。人形剪影阵列高速填入网格，矩形方块分裂成三组各自对齐，齿轮线稿与圆环叠加咬合旋转。画面蓝白反相一帧。俯视网格被黑色斜向色块横穿，切成多个不规则区域；刻度数字在特写中高速滚动。

| 句 | 画面 |
|---|---|
| 白色连线一次性铺满整张网 | ① 连线铺满 |
| 人形剪影阵列高速填入网格 | ② 剪影填入 |
| 矩形方块分裂成三组各自对齐 | ③ 方块分裂 |
| 齿轮线稿与圆环叠加咬合旋转 | ④ 齿轮咬合 |
| 画面蓝白反相一帧 | ⑤ 反相 |
| 俯视网格被黑色斜向色块横穿，切成多个不规则区域 | ⑥ 斜块切割 |
| 刻度数字在特写中高速滚动 | ⑦ 数字特写 |

**四句话，七个画面。** 机制有三条：

1. **句号 = 剪辑点。** 想切几刀就写几句。
2. **分号和逗号串联同一动作链**里的连续画面（"刀光转化为 A、B、C" = 三个画面）。
3. **并列结构自带密度**：一个顿号一个画面，免费。

### 为什么不能写编号清单

实测把提示词从散文改成「01 剪影入画 / 02 特写肩线 / 03 闪白」的编号清单后，节奏**反而变差**。

原因：视频模型的训练数据是自然语言画面描述（视频字幕、图文对），不是结构化列表。编号大概率被当成元信息/格式噪音而非画面内容。而且编号清单会丢掉句子里的连接描述——"刀尖划过画面，留下一条青蓝色几何轨迹"比"03 刀尖划过，青蓝轨迹"信息量更足。

**结论**：用散文，靠句子密度和动词提速，不靠排版。

## 4. 双轨解耦的完整范例

### 错误写法（句子边界 = 镜头边界）

```
0–3秒（台词1）：[一个场景的描述]
3–6秒（台词2）：[另一个场景的描述]
```

模型把每块读成一个场景单元，切点全落在句尾 → 配旁白的 PPT。

### 正确写法

**第一步**，台词轨单独写在【音乐】块里，只给时间点：

```
0至3秒念「过去，做成一件事得先有一家公司。」3.2至5.6秒念「招人、分工、协调，普通人碰不起。」5.6至9秒完全无旁白，只有音乐与画面。9至12.8秒念「现在，AI把这套东西压进了一个人手里。」
```

**第二步**，【镜头节奏】按自己的时间段走，**不标"台词N"**，密度独立：

```
0–3秒：纯白背景中一枚深蓝色人形剪影闪入画面，肩线边缘亮起青蓝色轮廓光。单帧白闪后，剪影头顶弹出白色细线与两个节点，层级树整层向两侧炸开。单个节点方块被网点覆盖并占满画面。金字塔状组织结构瞬间铺满全屏，深蓝节点密布，画面右侧的白色刻度条整条弹亮。
```

一句台词 3 秒，这里塞了 8 个画面。

**第三步**，在【动效要求】里写死解耦声明：

> 画面剪辑点只跟随鼓点，不跟随旁白的句子边界，一句旁白横跨七到八个画面，允许在句子中间切换画面；严禁一句台词对应一个画面。

三步缺一不可。只写第三步而分镜还是按台词分块，模型会照着分块走。

### 并列结构一词一刀

台词「招人、分工、协调」对应三个画面：

> 人形剪影阵列高速填入网格，矩形方块分裂成三组各自对齐，齿轮线稿与圆环叠加咬合旋转。

密度 +3，台词一个字没加。凡是台词里出现顿号并列，都是免费的切点。

## 5. 图形匹配转场

MG 最漂亮的一招：**A 形状 → 形变 → B 形状**，两个语义无关的东西靠形状相同接上。

例子：
- 「整张组织密网的节点、连线与刻度同时向内塌缩，收拢成一枚青蓝色光点；光点匹配转场为剪影胸口的那枚光点。」
- 「密集卡片矩阵向内塌缩成一枚圆环；该圆环匹配转场为时钟表盘的刻度环。」

写法：`[A]收拢/放大成一枚[形状]，该[形状]匹配转场为[B]`

**每支片至少安排 1–2 处。** 这是让画面显得"设计过"而不是"随机切"的关键，也是评价一份提示词专业度的直接指标。

好的匹配点通常出现在**语义转折处**——上一个概念的终点形状，正好是下一个概念的起点形状。

## 6. 景别层次

全景切全景永远不来劲。景别本身就是节奏来源。

四档：**满屏全景 → 中景 → 局部特写 → 图形微观特写**

规则：**连续两个画面不用相同景别。**

无角色时，"特写"的对象是图形：单个节点方块、刻度数字滚动、圆环的一段弧、网点的局部。

有剪影时，可特写的部位：**肩线边缘、胸口、手部**——这三处不需要五官，一致性成本低，但能提供高信息量的近景。

## 7. 失败模式速查

| 症状 | 病因 | 处方 |
|---|---|---|
| 节奏拖沓，像慢镜头 | 用了渐进性动词 | 查动词表，全部替换 |
| 像配旁白的 PPT | 台词轨与镜头轨没解耦 | 补三步解耦 |
| 画面数够但观感还是空 | 元素库太单薄，来回就那几样 | 扩元素库，每镜换组合 |
| 切得很碎但不好看 | 缺图形匹配转场，纯随机切 | 安排 1–2 处匹配转场 |
| 一片无意义闪烁 | 密度超出模型执行力 | 15 秒档降到 24–26 镜，或改分段生成 |
| 出现真实照片质感 | 禁令清单不够具体 | 点名禁掉该题材最易写实的物件 |
| 剪影长出一张会动的嘴 | 没写"画外音、不需要口型" | 补上那句 |
| 各段之间风格漂移 | 风格锁没有逐字复制 | 检查是否写了"同上"或改写 |
