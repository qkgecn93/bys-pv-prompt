## 1. 五块输出模板

方括号是待填项。**逐字相同的只有三样：声明句（除时长外）、【画面】整块、【动效要求】整块。**
【镜头节奏】、密度句、【音乐】块里的段落位置描述（几秒进鼓/怎么推/怎么收）本来就该按段变——见第 5 节。

```
生成一支[N]秒、[画幅]横版/竖版、纯二维日式赛璐璐动画结合抽象Editorial MG平面设计的[片型]。全片保持纯二维平面，禁止3D，禁止立体建模，禁止真实空间纵深，禁止三维透视渲染，禁止CG质感。原创画面，不出现任何真实企业Logo、真人形象或现成素材。

【音乐】
[BPM]BPM[曲风]，融合[乐器与音效清单]。开场[怎么起]，[N]秒后鼓点进入，[后半怎么推]，结尾[怎么收]。

[模式A追加旁白段，见第5节]

【画面】
[配色名]视觉风格：[主色1]、[主色2]、[主色3]、纯白与黑色构成高反差画面，[点缀色]只用于[限定用途]。硬边日式赛璐璐结合扁平Editorial MG与游戏UI线稿。一切元素高度平面化、图形化、剪影化，像一张动态平面海报被不断拆解和重新组合，空间允许不合理倾斜、翻转与压缩。

[有角色时]人物为无面黑色剪影，只有肩线与头部轮廓，没有五官，没有材质，没有立体光影，阴影只有一至两层；剪影的肩线边缘、胸口与手部可作局部特写。

[场景]不表现为真实[场景类型]，只由二维图形构成：[L4符号库，6-10项] 与 [L2通用图形库，6-10项]。构图大面积留白，元素在每个画面之间不断更换组合。

【镜头节奏】
[时间段1]：本段共[N]个画面，平均每[X]秒切换一次。[5-8个短句，瞬间性动词，句号即剪辑点]
[时间段2]：本段共[N]个画面，平均每[X]秒切换一次。[同上]
...

【动效要求】
所有转场跟随鼓点完成。[模式A追加双轨解耦句]

所有形态变化以弹出、闪现、劈入、划过、反相、碎裂、塌缩、拼合和图形替换完成，不使用生长、展开、浮现等渐进动作。使用斜向擦除、圆环扩张与塌缩、剪影反相、图形拆解、单帧白闪、蓝白负片闪烁、图形匹配转场与短促Glitch。景别在满屏全景、中景与局部特写之间高频跳切，连续两个画面不使用相同景别。运镜只允许平面内的平移、缩放与快速推近，不允许任何三维镜头运动。

避免[禁令清单，见第4节]。
```

**⚠️ 密度句的位置**：写在【镜头节奏】每段首句，**不写在【动效要求】里**。因为【动效要求】是要逐字复制的风格锁，而密度必须按段爬坡，混在一起必然打架——实测翻车过。单段成片不受此限。

**双轨解耦句**（模式 A 必写，逐字）：

> 画面剪辑点只跟随鼓点，不跟随旁白的句子边界，一句旁白横跨七到八个画面，允许在句子中间切换画面；严禁一句台词对应一个画面。

## 2. 六套配色预设

每套都注明**语义倾向**——选配色本质是选情绪，别只看好不好看。

### ① 冷蓝都市（默认）
- **色**：深海蓝、钴蓝、青蓝、纯白、黑；猩红只用于危险与警示
- **语义**：理性、科技、孤独、午夜、时间循环
- **偏好元素**：时钟刻度、圆环、月相、蝴蝶、扫描线、管道线稿、高楼轮廓
- **适合**：科技、AI、认知、个体处境、深夜叙事

### ② 红黑博弈
- **色**：深红、猩红、绛红、纯白、黑
- **语义**：对抗、风险、规则、不确定性、零和
- **偏好元素**：概率刻度、对局网格、卡片阵列、圆形代币、天平、倒计时环、分割线、UI 框线
- **适合**：竞争、风险、决策、对抗、行业厮杀
- ⚠️ **不要滑向赌具**：扑克花纹、筹码、骰子、赌桌这类具象赌博符号一律不用。国内内容平台对赌博类视觉是硬红线，视频模型本身也常直接拒绝生成。要表达"下注感"就用抽象的概率刻度与代币圆点，视觉张力一样够。

### ③ 黑金资本
- **色**：纯黑、暗金、香槟金、纯白；深灰过渡
- **语义**：权力、资本、层级、秩序、稀缺
- **偏好元素**：曲线刻度、方块堆叠、天平、齿轮线稿、金线分割、印章方块
- **适合**：商业、财经、阶层、行业格局

### ④ 酸绿故障
- **色**：荧光绿、青柠、纯黑、纯白；品红只用于错误提示
- **语义**：反叛、失控、异常、赛博、系统崩溃
- **偏好元素**：终端光标、代码行剪影、Glitch 色散、错位扫描线、报错框、进度条
- **适合**：技术批判、系统性问题、崩溃、失序

### ⑤ 米白极简
- **色**：米白、浅灰、炭黑、纯白；橙红只用于强调
- **语义**：冷静、克制、学术、留白、日常
- **偏好元素**：细线网格、几何体线稿、箭头、层级树、公式排版、圆点阵列
- **适合**：知识科普、方法论、教育、需要长时间垫在人声下的 B-roll

### ⑥ 靛紫东方
- **色**：靛青、藏蓝、绛紫、纯白、黑；朱砂只用于点睛
- **语义**：神秘、传统、命运、循环、内省
- **偏好元素**：圆窗、云纹几何化、卦象刻度、月相、竖排版式框、水波线
- **适合**：文化、哲学、心理、命运感叙事

## 3. 图形元素库

**L2 通用图形库**（题材无关，任何片子都可用）：

圆环、进度环、细线刻度、数字计数器、网格、俯视网格、扫描线、网点、几何切片、斜向色块、UI 框线、分割线、翻页卡片、点阵、连线、箭头、遮罩条、单帧闪白块

**关键原则：元素过剩。** 参考 PV 的元素库永远比实际用到的多，每个镜头换一批组合。元素单薄是画面显得"空"和"慢"的隐藏原因之一——只有四五种元素，切来切去还是那几样，观感上就不密。

L4 题材符号库见 `concept-map.md`。

## 4. 三级禁令清单

按需叠加，写进【动效要求】末尾。

### 通用禁令（永远写）
普通淡入淡出、渐变过渡、无意义快切、暖色阳光、霓虹赛博朋克街景、杂乱文字、写实 3D

### 平面档追加（本 Skill 永远写）
立体建模、真实透视、景深、CG 质感、真实空间纵深

### 节奏追加（高密度档写）
节奏拖沓、长镜头、平滑生长动画、缓慢展开、画面跟着句子走

### B-roll 追加（低密度档写）
复杂连续打斗、满屏文字、强剧情动作、标题落板、快速蒙太奇

### 模式 A 追加
人物开口说话的镜头、嘴部特写

### 题材追加（按题材填）
真实办公室场景、真实电脑与手机设备、真实品牌包装⋯⋯凡是这个题材里最容易被模型画成写实照片的东西，都点名禁掉。

## 5. 音乐块模板

结构：`BPM` + `曲风` + `乐器音色清单` + `开场怎么起` + `几秒进鼓` + `后半怎么推` + `结尾怎么收`

**成熟范例**（来自参考）：

> 132BPM 冷调日系 Electro Rock，融合电子鼓、低沉 Bass、碎拍、空灵钢琴与神秘女声哼唱；开场只有脚步、钟表滴答和低频脉冲，8 秒后鼓点进入，后半节奏逐渐加速，结尾钟声重击后突然抽空。

**⚠️ 分段生成时的陷阱**：上面这个模板是为 20 秒整片写的（"8 秒后鼓点进入"）。切成 8 秒 B-roll 段后，**"几秒进鼓 / 后半怎么推 / 结尾怎么收"三项必须按段重写**，不能照抄——否则每一段都在做完整的起承转合，拼起来会非常碎。

分段时的正确写法：整支片的音乐氛围描述保持一致（BPM、曲风、乐器清单不变），但每段只写该段在整体中的位置，例如「本段处于全片中段，鼓点已进入并保持稳定推进，段尾不做收束」。

### 模式 A 旁白段模板

```
中文[男/女]声画外音旁白，[语气形容词]，语速偏快，咬字干脆。旁白为画外音，画面中没有任何人物开口说话，不需要口型，不出现说话的嘴部特写。[N]至[N]秒念「[台词]」。[N]至[N]秒完全无旁白，只有音乐与画面。[N]至[N]秒念「[台词]」。
```

"画外音、不需要口型"那句不能省。省了模型会给剪影加一张会动的嘴。

## 6. 角色：默认不要，但要说清代价

**默认无角色**，因为 20 段里保持同一张脸非常难，一致性成本极高。

但代价是**丢掉景别层次**——没有可特写的东西，镜头只能全景切全景，永远不来劲。景别本身就是节奏来源（详见 `shot-writing.md` §6）。

**折中方案（推荐）**：用**无面黑色剪影**，只有肩线与头部轮廓，没有五官。这个风格本来就大量用剪影（参考原话："人物由黑色身体剪影、白色皮肤和蓝色轮廓光组成"），正好把模型的弱点变成风格特征。

- 剪影只需保持**发型轮廓 + 服装色块**一致，比保持五官容易一个量级
- 给它三个可局部特写的部位：**肩线边缘、胸口、手部**——这三处不需要五官，一致性成本低，但能提供高信息量的近景
- 故事类题材尤其推荐这条：有主角但不用扛脸部一致性

**什么时候可以要真角色**：单段成片（不需要跨段一致）、或用户明确提供了角色参考图且模型支持图生视频。
